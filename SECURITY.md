## Reporting a Vulnerability

**CRITICAL: Do not report safety-critical vulnerabilities through public GitHub issues.**

In a documentation assistant, a security flaw can lead to "hallucinated" safety instructions or data leaks. If you discover a vulnerability affecting the **RAG context injection**, **vector database poisoning**, or **sensitive doc exposure**:

1. **Email**: Send a detailed report to `electrohobby3d@gmail.com`.
2. **Impact**: Describe if the bug allows forcing the assistant to provide false pinouts, bypass access controls to internal manuals, or leak proprietary schematics.
3. **Response**: Initial acknowledgment within 48 hours.

We follow a coordinated disclosure policy to ensure hardware safety before public release.
