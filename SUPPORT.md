## 🐛 Bug Reports
If you found a real error in the retrieval logic or document parser, please open a **GitHub Issue** in this repository. 
*Please search existing issues before opening a new one.*

## ❌ What is NOT support?
- We do not provide support for non-robotic document sets.
- Please do not use Issues for "How to" questions.
